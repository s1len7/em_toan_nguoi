## 2. Prompt Engineering

Learn how to give AI clear instructions and get better results.

### Basic Prompt Structure

A good prompt often includes:

- **Role:** Who should the AI act as?
- **Task:** What should it do?
- **Context:** What information does it need?
- **Format:** How should it present the answer?

### Example

Weak prompt:

> Explain electricity.

Better prompt:

> Act as a friendly engineering teacher. Explain electricity to a beginner using simple English, three practical examples, and a short quiz.

### Practice Tasks

- Explain a technical concept in simple English.
- Summarize a long article into five bullet points.
- Compare two products in a table.
- Ask AI to improve an answer through follow-up questions.
- Verify important facts using reliable sources.

### Tip 1: Ask in English

AI models are trained mostly on English text. A question in English often uses **fewer tokens** and gets a **clearer, more accurate** answer.

| Question | Tokens | Answer quality |
| -------- | ------ | -------------- |
| Vietnamese | More | Sometimes less accurate |
| English | Fewer | Usually better |

"Fewer tokens" means less of your free daily limit is used, and the answer is usually easier to check.

You can still think in Vietnamese, then write the prompt in English. Example:

> Vietnamese: Giải thích điện là gì?
>
> English: Explain what electricity is in simple English.

### Tip 2: Keep prompts short and focused

A very long prompt can hide your main request. The AI may focus on the wrong part, forget an instruction, or give a vague answer.

**Too long:**

> I have been learning many things about electricity, and my teacher said..., and my friend told me..., and I read an article..., please explain electricity.

**Better:**

> Explain electricity in simple English. Use three practical examples.

Keep one main task per prompt. If you need more, split it into steps and ask one step at a time.

**Golden rule:** AI can make mistakes. Check important facts, calculations, and sources.

## 3. Markdown Basics

Markdown is a simple way to format text using plain symbols. AI chat services understand it, so you can use it to make prompts and answers easier to read.

| You want | Type this | You get |
| -------- | --------- | ------- |
| Heading | `## Title` | Large title |
| Bold | `**important**` | **important** |
| List | `- item` | Bullet point |
| Numbered list | `1. item` | Numbered step |
| Code | `` `code` `` | `code` |
| Link | `[name](https://site.com)` | [name](https://site.com) |

### Example prompt with Markdown

```text
Summarize the text below.

- Use 3 bullet points
- Write in simple English
- Add one **bold** key term per point

Text: ...
```

**Task:** Rewrite one of your old prompts using a heading, a short list, and one bold word. Compare the answer with the original.
